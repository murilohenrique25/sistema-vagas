# ai-service

Microsserviço de IA para extração de currículos em PDF, análise de candidatos e compatibilidade com vagas. Plataforma de vagas e recrutamento com cadastro de candidatos e empresas, currículos e serviço de IA para análise e compatibilidade com vagas.

## Tecnologias

- Python
- FastAPI
- LangChain
- Integração OpenAI
